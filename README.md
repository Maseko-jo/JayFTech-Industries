# JayFTech Industries

> Healthy tech for South African small businesses. Real work for young techs.

Founder-led tech support and build service for SA startups and small-to-mid businesses. It starts with
Jordan doing the work himself and grows into a vetted network of graduates and technicians.

## The website

React + TypeScript + Tailwind, built with Vite. Cloud-white background, frosted glass panels, ink-black accents
and iOS-style spring motion (scroll reveals, slide-up sheets, segmented tabs).

```
npm install
npm run dev      # local preview at http://localhost:5173
npm run build    # production build into dist/
```

- Page sections live in `src/components/`. Shared motion helpers are in `src/components/motion.tsx`.
- All wording, prices, skills, wellness questions and roadmap phases are in `src/data/mockData.ts`.
- Forms are a **preview**: they don't send anything yet.
